### 3-3. 양쪽을 잇는 것 (Phase 3)
- **입고 요청 게시판**: 식당이 "마포구 고깃집, 육류용 생막걸리, 월 50병" 요청 → 조건 맞는 양조장에 알림
- **시음회·샘플 매칭**: 양조장 → 지역 식당 묶음 샘플 투어
- 성과 보고: 양조장에 "이번 달 페이지 조회·문의·메뉴판 사용 수"

## 4. 추천 단계
### Phase 1 — 혼자서도 쓸모 있는 도구 (상대 가입 불필요, 3~4세션)
1. **서울·경기 모드**: 지역 선택(기본 서울·경기), 메인·지도·필터 모두 적용
2. **R1 메뉴 페어링 추천 + R2 가까운 양조장** (식당용 첫 화면)
3. **B1 내 술 진단 리포트** (양조장용 첫 화면) — 운영자가 양조장에 영업할 때 보여줄 "선물"
4. **R3 술 메뉴판 만들기**
5. 메인 구조 변경: "식당 사장님 / 양조장 대표님" 두 입구. 소비자용 메뉴(시음 노트·커뮤니티)는 숨김

### Phase 2 — 계정·연결 (검증 후, 3~5세션)
- 역할별 계정(양조장 / 식당), **사업자등록 상태 확인**(국세청 사업자등록 상태조회 API, 공공데이터포털)으로 인증
- B2 내 페이지 관리 + 이미지 업로드, B3 납품 조건, R4 입고 문의 → B5 문의함, 이메일 알림
- 관리자: 인증 승인, 문의 현황

### Phase 3 — 매칭·수익 (반응 보고)
- 입고 요청 게시판, 샘플 매칭, 양조장 유료 플랜(상단 노출·리포트 상세) 검토

## 6. 지금 기술 자산과의 연결
- 페어링·맛·생/살균·무감미료 → R1·R3 그대로 사용
- 좌표·찾아가는 양조장 → R2
- 충실도 점수·링크 생존·블로그·온라인 구매 → B1 진단 리포트의 핵심 지표 (지금까지 만든 품질 지표가 **양조장에게 파는 가치**로 바뀜)
- aT 갱신·판매 중단 → B1 "aT/더술닷컴에 판매 중단으로 나와 있음 — 맞나요?" 알림
- 카카오 API(보유) → R2 주소 변환, B4 판로 지도
