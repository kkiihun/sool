# 메인 UI 개편 방향 검토 — 2026-10-10 17:40

질문: 메인 UI 를 손보면서 "술 카드 정보가 완벽한 술"을 먼저 보여주는 게 맞나, 다른 걸 먼저 해야 하나?

## 1. 현재 데이터 (운영 DB, 1,250 제품)
술 카드 7개 항목 기준 충실도: 주종 · 원료 · 맛 · 페어링 · 설명 · 지도 위치 · 살아 있는 구매 링크

| 채운 항목 수 | 제품 수 | 비율 |
|---|---|---|
| 7 (완벽) | 345 | 28% |
| 6 | 487 | 39% |
| 5 | 268 | 21% |
| 4 이하 | 150 | 12% |

빠진 항목: 구매 링크 487 · 페어링 420 · 맛 416 · 지도 107 · 주종 73 · 원료 47 · 설명 43

그 밖에:
- **이미지가 있는 제품은 2개뿐** → 지금 메인 카드는 큰 빈 정사각형에 🍶/🥃 이모지가 대부분을 차지함 (가장 큰 시각적 문제)
- 이용자 데이터가 거의 없음: 감상 40 · 리뷰 3 · 시음 노트 6 → 평점·인기순은 의미 없음
- 영문/한글 문구가 섞여 있음 ("Elevate Your Sense", "Explore Profile" 등)

## 2. 판단
**메인 UI 개편을 다음 작업으로 하는 게 맞다.** 이유:
1. P7 로 데이터는 붙었지만 메인 첫 화면은 여전히 "이름순 + 빈 이미지" → 파이프라인의 가치가 첫 화면에서 안 보임
2. 포트폴리오 관점에서 "데이터 파이프라인 결과가 서비스 UX 를 바꿨다"를 보여주는 가장 직접적인 화면
3. 개발 비용이 작음 (백엔드 정렬 1개 + 카드 디자인)

단, "완벽한 술만" 보여주는 게 아니라 **정렬 기준으로** 쓴다. 정보가 부족한 술도 검색·필터에선 나와야 한다.

### 먼저 할 것 (5분, 사용자)
- ⚠️ 운영 관리자 비밀번호 변경 — 공개 repo 히스토리에 `admin1234` 있음. 메인 UI 보다 우선

### 병행 (사용자 30~40분)
- P3 주종 라벨링 — 메인에 자동 분류 '추정' 주종이 보이므로, 정확도 수치가 있어야 "추정" 표시를 뗄지 결정 가능

## 3. 개편안
### U1. 충실도 점수 (데이터)
- 파이프라인 analyze 단계에서 제품별 `card_score`(0~7)와 빠진 항목 목록 계산 → `analytics_sool_profile` 에 컬럼 추가
  - 테이블에 컬럼이 늘어나므로 ALTER 필요 (create_all 은 기존 테이블을 안 바꿈) → 마이그레이션 스크립트 1개
- status.json 품질 지표에 분포 기록 → 관리자 개요에 "완벽 카드 28%" 추이 (데이터 품질 KPI)
- 대안: API 에서 SQL 로 바로 계산 (마이그레이션 없음, 더 빠름). 하지만 품질 지표를 파이프라인이 관리한다는 그림이 포트폴리오엔 더 좋음 → **파이프라인 쪽 권장**

### U2. 메인 화면
- 기본 정렬 **"추천순" = 충실도 높은 순 → 수상 → 찾아가는 양조장** (이름순·도수순은 선택지로 유지)
- 카드 재디자인: 이미지 영역을 줄이고 **술 카드 요약**을 보여줌
  - 주종 색 띠 + 도수 · 원료 한 줄 · 맛 태그 2~3개 · 페어링 1~2개 · 배지(찾아가는·생·무감미료·온라인 구매)
  - 이미지가 없으면 주종 색 그라데이션 + 주종 이름 (이모지 대신)
- 상단: 큰 영문 히어로 → 짧은 한글 소개 + **빠른 필터 칩**(무감미료·생·찾아가는 양조장·페어링) 을 바로 노출 (지금은 Filters 버튼을 눌러야 보임)
- 섹션 추천(선택): "이번 주 찾아가는 양조장", "육류와 어울리는 술" 같은 가로 줄 2~3개
- 문구 한글화 (메인 + 상세 영문 제목)

### U3. 하지 않을 것
- 이미지 수집(크롤링): 저작권 문제, 출처 불명확 → 하지 않음. 필요하면 나중에 관리자 업로드 기능
- 정보 부족 제품 숨기기: 하지 않음 (정렬로만)
