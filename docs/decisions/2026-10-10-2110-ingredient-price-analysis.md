## 1차 구현 (이번)
| 단계 | 내용 |
|---|---|
| 수집 | 21개 원료 × 2021-01~현재, 월 단위 중도매 행 전체 → warehouse `ingredient_price`. 받은 달은 `ingredient_fetch` 에 기록, 최근 2개월은 매 실행 다시 받음 |
| 집계 | 상품 등급만 → 날마다 시장 간 **중앙값** → 월평균 (원/kg). 시장 수가 바뀌어도 덜 흔들리게 |
| 지표 | 최근 월 가격, **전년 같은 달 대비**, 최근 3개월 추세, **싼 달**(연평균 대비 비율의 달별 중앙값 하위 3개 = 출하기 근사), 변동계수(24개월) |
| 연결 | 제품 원재료 문구 → 원료 매칭 (포도당·배합·찹쌀 오인 방지 패턴) → `analytics_sool_ingredient` |
| 화면 | `/owners/ingredients` 원료 시세, 양조장 리포트 '주원료 시세' |

## 다음 분석 후보
1. **원가 압력 지수 (양조장별)**: 제품 원료 구성 × 원료 전년 대비 → "내 술 원료비 체감 +x%" (원료 배합비는 모르므로 '주원료 = 첫 번째 원재료' 가중)
2. **제철 원료 → 계절 술 추천**: 싼 달(출하기)에 그 원료로 만든 술을 메인·식당 추천에 노출 ("지금이 제철인 사과로 빚은 술")
3. **품질(등급) 차이**: 상품·중품 가격 차이가 큰 원료 = 품질 프리미엄이 큰 원료 → 양조장 원료 선택 참고
4. **지역 연결**: 시군구별 가격 + 원료 산지 집중도(P6: 오미자 경북 등) → "지역 원료로 만든 술" 근거
5. **시장 분석 보강**: 원료 가격 추세와 주종별 제품 수·신제품(aT 갱신 변경 감지) 관계
6. 소매 가격(구분 01)은 양이 많아 필요할 때 품목을 좁혀서
