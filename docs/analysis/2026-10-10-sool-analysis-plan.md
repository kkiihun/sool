# sool 분석 계획 v2 — "이 술이 뭔지 → 어디서 맛보나 → 시장은?" (2026-10-10)

> 사용자 질문의 흐름을 그대로 분석 구조로 삼는다.
> **① 술 이해 (Product)** → **② 어디서 맛보나 (Place)** → **③ 시장 (Market)**
> ①이 ②의 검색 키가 되고, ①+②가 쌓여야 ③이 나온다.

## ① 술 이해 — "이 술은 무엇인가" (술 카드)
제품 하나를 설명하는 표준 프로파일을 만든다. 상세 페이지·검색·추천·②의 검색 키가 모두 이걸 쓴다.

| 항목 | 출처 | 방법 |
|---|---|---|
| 주종 | 이름·원료·도수 | 규칙(완료, 94% 제안) → 정확도 측정 → LLM 보완 |
| 원료 프로파일 | 성분 | 주원료(첫 원료), 특산 원료, 감미료·주정·보존료 여부 |
| 제조 특성 | 이름·성분·설명 | 생/살균, 탄산, 숙성(년), 증류 방식 |
| **맛 프로파일** | 특징 텍스트 1,090 | 맛 사전(단맛·산미·부드러움·탄산·바디·고소…) + 부정어 처리 → 축별 점수. sense 40건으로 검증. 이후 LLM 추출로 고도화 |
| **페어링** | 특징 텍스트 | 음식 사전 → 태그 (회·고기·전·치즈·디저트…) 주의: '전'은 '전통'과 구분 필요 |
| 인증·수상 | 특이사항·수상경력 | 찾아가는 양조장, 식품명인, 무형문화재, 품평회 등급 |
| 도수·용량 | 기존 | |

산출물: `mart_sool_profile` (제품당 1행) → 상세 페이지 "술 카드", 필터(무감미료·생·찾아가는 양조장·페어링), 속성 기반 "비슷한 술"

| 공식 홈페이지 | 링크 1,070 | 링크 생존 검사, 쇼핑몰 연결 여부 | ✅ |

## ③ 시장 — Market
①②가 쌓이면 나오는 질문들:

| 질문 | 지표 | 사용처 |
|---|---|---|
| 지역은 무엇을 만드나 | 지역×주종 입지계수 (첫 결과: 충북 과실주 40%, 제주 증류주 46%, 전남 탁주 52%) | 탐색·지역 콘텐츠 |
| 원료가 지역성을 만드나 | 원료×지역 집중도 (감귤 16 중 제주 14, 오미자 39 중 경북 16) | 원료 지도 |
| 얼마인가 | 주종별 100ml 당 가격 분포, 프리미엄 구간 | 소비자·양조장 리포트 |
| 쉽게 살 수 있나 | 온라인 구매 가능률 (주종·지역·양조장 규모별) | **유통 격차** 발견 |
| 숨은 명주 | 수상·명인·찾아가는 양조장인데 판매처 적음 | 콘텐츠·큐레이션 |
| 대중형 vs 프리미엄 | 감미료 사용률 (탁주 17% / 약주 2%), 무감미료 비중 × 가격 | 시장 분절 |
| 경쟁 구조 | 양조장 429곳 평균 2.5개 (롱테일), 제품 경쟁군 | 양조장 포지셔닝 리포트 (수익) |
| 맛볼 수 있는 곳의 지역 격차 | 지역별 제품 수 대비 체험 양조장·보틀샵 수 | 지자체·관광 |

## 사이클 연결 (feedback)
- 맛 프로파일이 빈 제품, 판매처 0 제품 → 다음 수집 대상
- 사용자가 상세 페이지에서 "여기서 마셔봤어요" 제보 → 매장별 취급 데이터가 생김 → ②의 빈칸을 서비스가 채움

## 구현 순서
| # | 작업 | 필요 |
|---|---|---|
| P1 | CSV 시드를 collect 에 추가, `mart_sool_profile` (주종·원료·제조·인증·수상) | 없음 |
